# Rastreabilidade e decisões

Este diretório reúne os registros que conectam a OntoPrivacy às suas fontes e decisões de modelagem.

| Arquivo | Função |
|---|---|
| `MATRIZ_CONCEITO_FONTE_v2.xlsx` | matriz normalizada e de cobertura |
| `MATRIZ_CONCEITO_FONTE_v2.md` | versão textual da matriz |
| `REGISTRO_DECISOES_ONTOPRIVACY_v2.md` | decisões e limites consolidados |

A matriz distingue:

- fonte direta;
- fonte herdada ou relacionada;
- fundamentação transversal;
- definição autoral.

Os arquivos preservam a numeração técnica v2. Consulte [`../VERSIONAMENTO.md`](../VERSIONAMENTO.md).
