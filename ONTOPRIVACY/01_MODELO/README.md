# Modelo canônico da OntoPrivacy

Este diretório contém a linha de base técnica congelada da versão final da ontologia:

- `OntoPrivacy_v2.asta` - modelo editável no Astah;
- `OntoPrivacy_v2.png` - exportação visual do diagrama único.

Na dissertação e na documentação pública, esses arquivos correspondem à **OntoPrivacy v2**. Consulte [`../VERSIONAMENTO.md`](../VERSIONAMENTO.md).

## Como consultar

1. Use o PNG para leitura rápida e inserção em documentos.
2. Use o ASTA para inspecionar definições, estereótipos, cardinalidades e restrições.
3. Consulte o Catálogo para definições textuais e rastreabilidade.

> [!NOTE]
> O atributo `Finalidade.descrição` e a restrição de `Dado Pseudonimizado` estão registrados no ASTA, mas não são exibidos no PNG por decisão de apresentação.
