# Histórico da OntoPrivacy

## OntoPrivacy v1

A OntoPrivacy v1 é a versão inicial desenvolvida e aplicada em Mori Junior et al. (2025). Ela permanece como base histórica:

- da abordagem de anotação semântica para OpenAPI;
- do Estudo I sobre a API Pix;
- do GERPD v1.0;
- do Estudo II.

O arquivo `OntoPrivacy_v1.png` é preservado neste diretório para comparação e rastreabilidade.

## Evolução para a v2

A OntoPrivacy v2 é a versão conceitual final da dissertação. A evolução incluiu Identificabilidade, Finalidade, Dado Pseudonimizado, estruturas de dados e revisão das classificações UFO/OntoUML.

A evolução não modifica retroativamente os artefatos históricos.
