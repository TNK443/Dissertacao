# Templates do GERPD

## Finalidade

Esta pasta disponibiliza modelos estruturados para reutilização do GERPD em outras aplicações.

## Conteúdo

| Arquivo | Função |
|---|---|
| `Template_MPA_v1.0.xlsx` | Estrutura canônica da Matriz Padrão de Aplicação, com os 15 campos definidos no GERPD v1.0. |
| `Template_Matriz_Rastreabilidade_v1.0.xlsx` | Estrutura da Matriz de Rastreabilidade da Etapa 7, com os status `Completo`, `Parcial` e `A validar`. |
| `Template_Revisao_Humana_v1.0.xlsx` | Modelo de registro baseado no formato utilizado para consolidar RH-01 a RH-10 no Estudo II. |

## Observação metodológica

Os templates de MPA e Matriz de Rastreabilidade refletem diretamente as estruturas canônicas do GERPD v1.0. O template de revisão humana é um **modelo operacional derivado do Estudo II** para documentação dos ajustes humanos; ele não cria uma nova etapa do GERPD.

## Relação com a dissertação

Os instrumentos correspondem às estruturas apresentadas no Capítulo 3 e utilizadas no Estudo II, Seção 4.3.
