# Adendos de Retorno - AR-01 a AR-07

## Finalidade

Registrar as atualizações explícitas geradas pela própria IA quando etapas posteriores revelaram necessidade de retornar a uma etapa anterior, sem sobrescrever a saída original.

## Conteúdo

- `AR-01.md` a `AR-07.md`: textos completos de cada Adendo de Retorno.
- `Adendos_AR01_AR07_Completo.md`: consolidação textual de origem.
- `Adendos_Retorno_EstudoII_v1.0.csv`: índice machine-readable com etapa de geração, etapa afetada e registros associados.

## Interpretação

Os AR integram a mesma aplicação formal. Eles não representam novas execuções e não apagam as respostas anteriores.
