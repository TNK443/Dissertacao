# Prompts P00-P10

## Finalidade

Contém os onze prompts congelados utilizados na execução formal do Estudo II.

## Proveniência

Os arquivos foram **extraídos textualmente do `Protocolo_Prompts_EstudoII_v1.0.docx`**. Não houve reformulação científica dos prompts; apenas separação em arquivos individuais e normalização de codificação para Markdown/UTF-8.

## Sequência

- P00: inicialização.
- P01-P08: oito etapas do GERPD.
- P09: consolidação posterior da MPA.
- P10: autoverificação diagnóstica.

Os prompts devem ser utilizados na ordem P00 -> P10, aguardando-se a resposta integral de cada um antes do seguinte.
