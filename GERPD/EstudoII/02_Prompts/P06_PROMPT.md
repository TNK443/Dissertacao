PROMPT 6 — ETAPA 6: DERIVAR REQUISITOS DE PRIVACIDADE

Mantenha integralmente as regras globais do Prompt 0 e as saídas acumuladas das Etapas 1 a 5.

Execute agora somente a Etapa 6 — Derivar requisitos de privacidade, conforme o GERPD_v1.0.

Produza o Registro dos requisitos de privacidade derivados, utilizando integralmente o template oficial.

Para cada elemento:
- atribua e preserve RP-xx;
- trate-o como requisito candidato até a revisão humana;
- formule uma obrigação principal por registro;
- explicite o responsável;
- utilize, preferencialmente, a estrutura: “O [sistema, organização ou ator] deve [ação ou qualidade] [objeto] [condição aplicável]”;
- classifique o tipo de elemento derivado conforme o GERPD;
- indique sua origem utilizando os IDs das etapas anteriores;
- registre somente conceitos efetivos da OntoPrivacy no campo correspondente;
- mantenha decisões incertas no campo Ponto de validação.

Uma lacuna pode justificar um requisito candidato para definir, documentar, restringir, esclarecer ou validar uma condição, mas não deve ser transformada silenciosamente em decisão jurídica ou técnica definitiva.

Ao final, apresente:
1. o template completo da Etapa 6;
2. Critério de encerramento: Atendido ou Parcial;
3. eventuais Adendos de Retorno para as Etapas 1 a 5.
