# Respostas brutas P00-P10

## Finalidade

Preservar a evidência primária produzida pelo ChatGPT durante a execução formal.

## Regra de preservação

Os arquivos `P00_RESPOSTA_BRUTA.md` a `P10_RESPOSTA_BRUTA.md` são cópias integrais das respostas armazenadas no material do estudo e **não foram editados, corrigidos ou reformatados neste pacote**.

`EXECUCAO_COMPLETA_P00-P10.md` é apenas uma visão derivada para leitura contínua, intercalando o prompt congelado e sua resposta bruta. Em caso de divergência de apresentação, os arquivos individuais de resposta são a evidência primária.

## Relação com a dissertação

A preservação das respostas brutas fundamenta a distinção entre execução formal, autoverificação e revisão humana descrita nas Subseções 4.3.3 a 4.3.6.
