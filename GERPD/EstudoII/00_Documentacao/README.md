# Documentação do Estudo II

## Finalidade

Reúne os documentos que descrevem o protocolo congelado, o ambiente metodológico e a organização dos artefatos do Estudo II.

## Conteúdo

- `Protocolo_Prompts_EstudoII_v1.0.pdf`: protocolo operacional congelado P00-P10.
- `METADADOS_EXECUCAO_EstudoII.json`: metadados objetivos da execução formal.
- `GLOSSARIO_IDENTIFICADORES.md`: significado dos identificadores AN, DP, AG, OP, FA, RP, PA, AR, RH e MPA.
- `MAPA_ARTEFATOS_ESTUDOII.md`: mapa de arquivos, função, proveniência e relação com a dissertação.

## Proveniência

O DOCX do protocolo é um artefato congelado anterior à execução. O PDF foi derivado do DOCX apenas para leitura. Os demais arquivos são documentação derivada dos materiais já validados, sem reexecução do estudo.
